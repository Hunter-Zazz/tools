EVIDENCE NOTES

What this means

  • Spent: the output is publicly linked to a later spending transaction.
  • Unspent: no spending transaction is currently recorded for that output.
  • Expand search: fetches at most ten additional transactions; hidden results are not pre-computed.
  • Custodial boundary: exchange attribution will be shown only with a source and confidence level.
  • Evidence package: ZIP containing README, PDF, CSV, JSON, XML and SHA-256 hashes.

Legal-channel rule: do not identify, confront, contact, hack or independently recover assets from a suspected offender. Preserve evidence and report through the proper authorities.

The package is built locally in your browser; generating it does not upload the trace to a Poseidon server.

Provider: mempool.space public REST API. Public rate limits apply.
