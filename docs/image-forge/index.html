FIELD NOTES // FORMAT SELECTION

Which format should I use?

01

WebP

Best general default for modern sites: strong compression, transparency and broad browser support.

02

AVIF

Excellent compression for photographic content when the current browser can encode it.

03

JPEG

Useful for photographs where maximum compatibility matters. JPEG does not support transparency.

04

PNG

Use for lossless output, crisp interface artwork or transparency when file size is secondary.
