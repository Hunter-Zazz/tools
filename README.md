# Hunter + Zazz Tools

Finished public tools from the Hunter + Zazz / Project Poseidon ecosystem.

The Command Deck is the primary portfolio. This repository is the public source/deployment mirror for released tools.

## Tools

### Poseidon Ledger
Read-only Bitcoin transaction-flow tracing and evidence packaging.

- Public blockchain data only
- No wallet connection
- No private keys
- Bounded 10-transaction expansion
- PDF / CSV / JSON / XML evidence
- One-click ZIP evidence package
- Evidence-first, legal-channel reporting doctrine

Launch: https://hunter-zazz.github.io/tools/poseidon-ledger/

### Poseidon Image Forge
Local-first browser image conversion and optimisation.

- WebP / AVIF / JPEG / PNG output
- Resize and quality controls
- Batch conversion
- SEO-friendly filenames
- Metadata-free browser export
- Images processed locally in the browser

Launch: https://hunter-zazz.github.io/tools/image-forge/
